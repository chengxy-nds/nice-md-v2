01. 段落与行内样式

欢迎体验 EasyMD / NiceMD 的 默认经典主题（山海 · 经典）。该主题以舒适的冷调藏蓝作为视觉主线，搭配雅致的温润排版，专为中长篇微信技术分享与深度叙事量身定制。这里展示丰富的行内语法：粗体强调文本（Bold），以及 斜体弱强调（Italic），还可混合嵌套使用 粗斜体文本组合。

同时完整支持 删除线文本（Strikethrough）、浅蓝高亮标记（Highlight）、行内代码 const theme = "Classic-Indigo"，化学分子式 H2O 下标与矩阵幂次 AT 上标，以及标准带文末锚点的引用链接「NiceMD 架构规范」[1]。
